# muse-robotband1126n-entry

> Rust in Peace — hit single: 'Your Update Is Ready (Please Restart Me Gently)'

A metal band of robots, and a love song disguised as a system prompt. This repository holds the complete Name the Robot Band submission and the program that announces the act.

## Running the program

Execute `main.py` under Python 3. It uses only the standard library, performs no network access, and always writes identical bytes: the band line with a trailing newline, as `entry.txt` in `MAKEFUN_OUTPUT_DIR` when set and in `/output` otherwise.

## Selection notes

The brief requires a funny robot band name plus a few words on its hit song, with the song adding a second laugh that fits the name. The Loose Bolts leaned on a sweet charging-dock ballad while their name did little. Ctrl+Alt+Defeat reached for a keyboard pun readers have met. Rust in Peace is a name you would repeat to a friend, and its single converts the most dreaded sentence in computing into a tender request to be restarted gently — name and song fire together, with nothing left over.
